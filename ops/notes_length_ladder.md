# 第二阶段第 0 步：长度阶梯 + A1 强制预算曲线（纯 CPU、只读）

**第二阶段不在 OSF 注册的 stage-1 协议之内。** 模板在本计算之前冻结于 commit `f887662`。
脚本 `ops/analysis/length_ladder.py`，原始输出 `ops/analysis/length_ladder.out.json`。

口径：
- **主块 = stage-1 报告集（500 题）**：A1 收敛 checkpoint 的原生轨迹取自 `06_diagnose` 的 `diag_native_test`，即强制预算曲线所用的同一批题、同一 checkpoint；A1 只取答对的 458 题，N 版本在同一 458 题上配对。
- 参考块 = 停止集：冻结模型（A1 step-0 eval，答对 284 题）与 A1 收敛（step-350 eval，答对 456 题）。
- token = Qwen3-4B 分词器对 think 文本重新分词；code point = 字符数；比特 = zstd level 19 压缩后字节 × 8。
- 带字典比特：110 KB 并集字典、level 19、seed 0，与 E1（`endpoints.zstd_dict_bits`）同设置，但**按题对半**（一半题的全部版本训练字典，另一半 229 题在所有版本上计算）；E1 按片段对半、只报均值，这里需要逐题配对，故改为按题。无字典比特在全部答对题上算。
- 比值给两种：中位数之比 / 逐题比值的中位数。

**事实（不作解释）**：

- 全部阶梯里最大的一级是 A1 → N1（token 0.063）。
